# 🩺 MedAssist AI — Intelligent Healthcare Chatbot

An AI-powered healthcare chatbot that predicts possible diseases based on user symptoms and provides interactive health-related assistance using Machine Learning and Natural Language Processing.

---

# 📌 About The Project

MedAssist AI is a smart healthcare assistant designed to help users understand possible health conditions through symptom-based interaction. The chatbot uses Machine Learning algorithms and Natural Language Processing techniques to analyze symptoms entered by users and generate possible disease predictions in real time.

The main objective of this project is to create an accessible and user-friendly healthcare support system that can provide preliminary guidance before consulting a medical professional.

The system combines AI, ML, and conversational interfaces to create a seamless healthcare experience.

# ⚙️ How It Works

The workflow of MedAssist AI is:

1. The user enters symptoms into the chatbot.
2. The system processes the input using NLP techniques.
3. The Machine Learning model analyzes symptom patterns.
4. The chatbot predicts possible diseases.
5. The response is displayed through an interactive interface.

# 🚀 Getting Started

Follow these steps to run the project locally on your machine.

## 📋 Prerequisites

Make sure you have the following installed:

- Python 3.9+
- VS Code or any Python IDE
- Git

---

# 📥 Installation & Setup

## 1️⃣ Clone the Repository

Open terminal or command prompt and run:

```bash
git clone https://github.com/your-username/MedAssist-AI.git
cd MedAssist-AI
```

---

## 2️⃣ Create a Virtual Environment

### For Windows

```bash
python -m venv venv
venv\Scripts\activate
```

### For Mac/Linux

```bash
python3 -m venv venv
source venv/bin/activate
```

---

## 3️⃣ Install Required Dependencies

Install all the required Python packages using:

```bash
pip install -r requirements.txt
```

If the project does not contain a `requirements.txt` file, install the packages manually:

```bash
pip install flask pandas numpy scikit-learn nltk
```

---

## 4️⃣ Run the Application

Start the Flask application using:

```bash
python app.py
```

OR

```bash
python main.py
```

---

## 5️⃣ Open in Browser

After running the application, open your browser and visit:

```text
http://localhost:5000
```

The AI Healthcare Chatbot will now be running locally on your system 🎉
